EDITING
Open index.html in a text editor. Near the bottom, update:
const HOST_WHATSAPP_NUMBER = "";
Enter the host's WhatsApp number using country code and digits only. This was not present on the card, so it remains blank. Date and venue have been filled from the card.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to a free account at https://github.com/
2. Create a public repository, for example vishal-smita-invitation.
3. Upload index.html to the repository root and commit.
4. Go to Settings → Pages.
5. Choose “Deploy from a branch”, select “main” and “/(root)”, then Save.
6. Wait for the public website URL to appear in Pages settings.
7. Open it on a phone and share it with guests.
